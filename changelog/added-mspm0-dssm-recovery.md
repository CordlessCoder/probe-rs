probe-rs can now recover an MSPM0 whose AHB-AP has stopped responding, which happens when main flash holds an image that faults the core as soon as it runs. Passing `--allow-erase-all` sends a mass erase to the boot ROM's mailbox and reattaches; without it, the attach fails with a missing-permission error rather than a bare fault. The erase covers main flash only and leaves NONMAIN, and so the device's debug access policy, untouched.
