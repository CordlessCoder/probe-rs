Added `probe-rs factory-reset`, which resets a target's non-volatile configuration to the manufacturer's default through a vendor sequence. MSPM0 devices implement it: a boot configuration the boot code cannot validate leaves a part that will not start its application, enable debug, or enter the bootloader, and this is the only documented way back. It needs `--allow-factory-reset`, which `--allow-erase-all` does not imply, and it leaves the device with no program on it.
