Added a `factory_reset` permission, set with `--allow-factory-reset` or `Permissions::allow_factory_reset`, for operations that reset a device's non-volatile configuration rather than only erasing its memory. It is deliberately not implied by `--allow-erase-all`: on some devices that configuration decides whether the part can be debugged at all, so consenting to lose an application is not the same as consenting to lose that.
